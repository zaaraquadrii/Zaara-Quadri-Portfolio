# Zaara Quadri Portfolio

A personal portfolio website for **Sayeda Zaara Quadri**, a Software Engineer and Full-Stack Developer based in Hyderabad, India.

The site showcases experience across full-stack development, enterprise applications, AI/ML solutions, APIs, dashboards, and freelance web projects.

## Live Projects

The portfolio includes live previews and links to real client websites:

- [Veedentes](https://veedentes.com) - Clinic website and appointment automation
- [Shakumaku](https://www.shakumaku.com/) - Premium Shopify e-commerce experience
- [RedFlow Foundation](https://redflowfoundation.com/) - Responsive charity and donation platform

## Features

- Responsive portfolio layout for desktop and mobile
- Project cards with embedded live website previews
- Direct links to production project websites
- Experience, education, skills, and learning sections
- Contact form that opens a pre-filled email draft
- Mobile navigation menu
- Portrait favicon and branded header image
- Smooth scrolling and subtle reveal animations
- Lucide icon system for interface actions

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
git clone https://github.com/your-username/your-repository-name.git
cd your-repository-name
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL shown by Vite in your browser.

### Create a production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## Customization

Project information is managed in `src/data/projects.js`. Update the project title, description, technologies, and `liveDemo` URL there.

The main portfolio sections and interactions are in `src/main.jsx`, while the visual system and responsive layouts are defined in `src/styles.css`.

## Deployment

This is a standard Vite application and can be deployed using services such as:

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

Use the following build settings for most deployment providers:

```text
Build command: npm run build
Output directory: dist
```
